# Track progress

Synchronize completed activities from the selected task backend, but mark a topic as mastered only when its evidence and mastery criteria are satisfied. Record timestamps, evidence links and assessment outcomes in `state/progress.json`.

Activity completion is not equivalent to learning. When evidence is insufficient, move the topic to evaluation or generate a focused review task.

Complete each tracking operation using `instructions/phase-completion.md`. Report the meaningful progress change, link relevant evidence or tasks, identify the next study action, and provide one exact command for the next check-in, evaluation or replan. Do not dump the entire progress state into chat unless requested.
